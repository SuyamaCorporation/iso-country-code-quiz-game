# ISO Country Code Alpha-2 Quiz Game

A fast-paced geography quiz game that tests your knowledge of ISO 3166-1 alpha-2 country codes with two modes: flash a code and guess the country, or flash a country name and guess its two-letter code.

## Features

- Two game modes: Code → Country (e.g. "JP" → guess "Japan") and Country → Code (e.g. "Germany" → guess "DE")
- 70+ countries from all continents covered
- 4-choice multiple choice format with instant feedback
- Score, current streak, and best streak tracking
- Auto-advances to next question after a short feedback delay
- Correct answer highlighted in green, wrong selection in red
- Streak and best-streak counters displayed prominently
- Total questions answered counter
- Mode switch resets the question without resetting scores
- Dark space-themed gradient aesthetic
